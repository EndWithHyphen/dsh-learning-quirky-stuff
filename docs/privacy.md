# 数据处理说明

本说明适用于学习画板插件及其 Chrome 配套扩展。项目维护者没有运营接收笔记的云端服务，也没有配置遥测或广告统计服务。

## 保存在本机的内容

DSH 数据目录保存笔记、图片、来源链接、总结、批注、分类、标签、复习安排、导入材料、图谱、模型输入记录和任务状态。浏览器存储保存当前标签页关联、未同步文字/画布/截图、同步队列与连接凭据。

信息图另行保留生成版本、当时引用的材料快照和手工编辑的画布；重新生成不覆盖旧版本。图形编辑及导出在本机进行。

这些数据没有额外的应用级加密。请使用操作系统账户保护、磁盘加密和你信任的备份位置。调试与报告问题时，不要公开数据目录、输入快照或连接凭据。

## 何时读取浏览器页面

- 你触发扩展图标或快捷键时，读取当前页标题和链接以创建或打开笔记。
- 你点击截图、粘贴图片或编辑笔记时，保存相应内容；截图可以记录当前视频时间。
- 你点击材料预览时，提取当前网页正文或可访问字幕，并可定位回对应段落。
- 你编辑的内容自动保存到浏览器草稿，并通过本机回环服务同步到 DSH。

扩展不持续抓取所有标签页正文。首次连接需在 DSH 中允许；可以随时撤销浏览器访问。

## 模型与互联网请求

你点击 AI 总结、系统学习、学习周报、图谱整理、专题分析、拓展或理解反馈时，所选功能所需的笔记文字、图片、材料片段、来源链接及你的输入，会交给你选择的模型提供方。系统学习开启「连接相关笔记」时会选择库内相关片段一起分析。周报在你点击生成后，使用所选周次的已有记录、复习作答与白板文字修订；不会后台自动发送。DSH 管理模型账户；使用 Codex 时由你已登录的本机 Codex CLI 发起模型请求。额度、费用和提供方的数据保留政策由对应账户与服务条款决定。

你选择联网探索或系统学习的「联网扩展资料」时，会搜索主题及研究问题并读取候选公开网页。系统学习检索阶段只传递提炼的主题问题，不附送整篇笔记或画布图像。材料 URL 导入会向对应网站请求正文；浏览器材料导入读取你已经打开的页面。普通总结不主动联网检索。

开启「自适应信息图」后，普通 AI 总结会在同一请求中按材料需要策划配图。单独点击「配图」或「重新生成」会把所选总结主题、关联原图与改图要求交给当前选择的模型；不会因此开启联网检索。仅打开、编辑或下载已有图不会调用模型。

macOS 图片识别和 PDF 文本提取在本机完成。Chrome 画布字体随扩展分发；DSH 画布保留 Excalidraw 的字体加载逻辑，使用某些非系统字体时可能请求其字体 CDN（esm.run）。字体请求不包含笔记正文。

## 删除与保留

移入回收站可以恢复。永久删除会清理对应笔记及插件管理的相关派生数据；浏览器重新连接后同步清理相应草稿和待处理操作。已导出的备份、你自行复制的文件以及模型提供方留存的数据，需要分别管理。

卸载程序不主动删除 DSH 数据目录。浏览器扩展卸载可能清除该扩展的本机草稿和设置，请先确认已同步。
